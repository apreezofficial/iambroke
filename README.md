# 🚨 SAPA 911 | I AM BROKE SCREAMER (Naija Edition) 📢🇳🇬

> The premier emergency screaming web application designed to shout **"I AM BROKE!"** across Nigerian languages (Pidgin, Yoruba, Igbo, Hausa, street slangs) and world languages with maximum comedic urgency.

## ⚡ Highlights

- **🔊 Multi-Lingual Screamer Engine**:
  - **Nigerian Pidgin**: *"SAPA DEY CHOKE ME OOO!"*, *"I DON BROKE DIE BABA!"*, *"CUT SOAP FOR ME NA!"*, *"MY ACCOUNT BALANCE NA ₦4.20!"*
  - **Yoruba**: *"KÒ SÍ OWÓ OOO! ẸGBÀ MI!"*, *"OWÓ TI TÁN PÁTAPÁTA!"*, *"EBÍ Ń PA MÍ OOO!"*
  - **Igbo**: *"ÈGÓ ADÍGHỊ KWA! NWANNE BIKONỤ!"*, *"ÈGÓ AGWỤ́LA PATAPATA!"*, *"ONYE GA-ENYEM URGENT 2K?!"*
  - **Hausa**: *"BA KUDI WALLAHI TALLAHI!"*, *"KUDI YA KARE GABAGADÍ!"*, *"TALAUCI NA KONA NI!"*
  - **Street Slangs**: *"ATM said insufficient funds with attitude"*, *"Garri water is my steady valentine"*
  - **Global Screams**: French, Spanish, Japanese, German, Italian, Brazilian Portuguese, Korean, and Arabic!
- **🚨 Web Audio Synthesizer**: Custom police sirens, Nigerian wahala 808 booms, empty cash register clicks, and vuvuzela horn blasts.
- **🗣️ Speech Synthesis**: Shouting voice engine with dynamic pitch & urgency.
- **📳 Earthquake Tremor**: Toggleable screen-shaking animations that shake your device with financial panic.
- **📈 Sapa-Meter Diagnostic**: Stages 1 through 5 from *"Small debit warning"* to *"Federal Disaster Zone"*.
- **📩 Urgent 2K Generator**: 1-click begging broadcasts with custom templates for WhatsApp and Twitter.
- **💳 Kuda-Less Parody Wallet**: Fake account balance of ₦1.14 with hilarious SMS charge debits.
- **🥣 Garri Survival Calculator**: Calculates remaining days of survival based on available cassava flake supplies.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/apreezofficial/iambroke.git
cd iambroke
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser. Turn up your volume for full comedic distress! 📢

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, React 18, TypeScript)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with custom animations and hazard themes
- **Audio**: Web Audio API Sound Synthesizer + Web Speech API
- **Icons**: Lucide React
- **Confetti**: Canvas Confetti (for failed Urgent 2K attempts)
